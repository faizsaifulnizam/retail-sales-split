## Planned dashboard — "Retail sales, split and rebased"

One interactive dashboard on Tableau Public, from the committed monthly extract:

- **Headline panel** — the latest month's chained-volume YoY and SA MoM beside the
  release's current-price figures, with a 10-year context line (industry = Total).
- **Industry contributions over time** — the monthly `contrib_prices_pp` per industry
  (the exact published-formula contributions) as a stacked bar or bump chart, so a viewer
  can see which industries carried or dragged each month, not just the latest.
- **Filter** — industry picker; retail and F&B separated by the `series_group` field
  (never combined into one number).

**Data:** [`../outputs/tableau_extract.csv`](../outputs/tableau_extract.csv) — monthly,
2016 → latest, one row per industry × month: index levels (volume/prices, original + SA),
YoY %, and contribution (pp of the current-price headline). Regenerated by
`python src/analysis.py`; a refresh re-pull updates it.

**Why Tableau:** one interactive view answers the "who carried it?" question across time;
the repo keeps the static figures + memo as the canonical read.
